# 界面口径：克制的工具感

来源：用户提供的 `minimalist-ui` 协议（Notion / Linear 一路的编辑器式极简）。
本文记录**在本项目落地时保留了什么、改了什么、为什么**，以及一条页面样板。

## 0. 为什么需要这份记录

原协议大半是给**营销落地页**写的：hero 区、FAQ 手风琴、伪 macOS 窗框、
picsum 占位图、滚动入场动画、环境光斑、`py-24` 巨留白、`max-w-4xl` 正文宽度。

本项目是**带侧栏的密集生产工具**：长列表、数据表、多层工作区。协议自己也写了
限制——「内容密集时极简会掩盖层级」「不要无故推翻既有品牌系统」。所以逐条照搬
是错的，下面写清楚哪些采纳、哪些不采纳。

## 1. 采纳

| 条目 | 落地方式 |
| --- | --- |
| 圆角要利落（最大 8–12px） | `tailwind.config.ts` 里把 `xl/2xl/3xl` 统一压到 10–12px，`--radius` 从 12px 收到 8px。全站约 880 处硬编码大圆角因此一次收敛，不必逐个改 |
| 阴影几乎不存在 | 覆盖 Tailwind 的 `shadow-md/lg/xl/2xl`，透明度压到 0.04–0.06 |
| 主操作实心、其余安静 | 每屏只有一个实心主按钮；次要操作用 ghost；破坏性操作用 ghost + 红字，不再是常亮的红色实心块 |
| 大容器不用胶囊形 | 卡片与主按钮不用 `rounded-full`；标签仍可用 |
| 颜色是稀缺资源 | 淡色底的告示牌改成普通文字；色彩只留给语义（告警、破坏性） |
| 排版建立层级，不靠盒子 | 摘要卡去掉自己的边框底色，改用左侧细线 + 留白 + 字重 |
| 语言平实具体 | 见 §3 |

## 2. 不采纳（及理由）

| 条目 | 不做的原因 |
| --- | --- |
| 换掉 Lucide 图标库 | 全站数百处引用，换库是纯风险、零功能收益。图标风格一致就够了 |
| 指定 SF Pro / Instrument Serif 等字体 | 这是中文应用。拉丁字体栈管不到汉字，汉字仍回落到系统字体；真要中文衬线得引 Noto Serif SC 一类，体积以 MB 计，为一点观感不值 |
| 暖色米白画布（`#F7F6F3`） | 应用有完整主题系统（浅色 / 深色 / 跟随系统 + 墨砚 / 暖纸 / 夜航）。要改只能改 token，不能把颜色写死进组件 |
| `py-24` / `py-32` 巨留白、`max-w-4xl` | 那是长文页的尺度。工具页一屏要放下列表和操作，照搬等于逼用户滚屏 |
| 滚动入场动画、交错出现、环境光斑 | 工作工具每次导航都演一遍会烦人，且拖慢密集列表 |
| 伪 macOS 窗框、picsum 占位图 | 落地页素材，产品内没有位置 |

## 3. 文案规矩

诊断出来的「AI 味」主要**不是**配色（全站只有 10 处渐变、零 emoji），
而是**每一层都在自我解说**。禁止以下写法：

- **营销式眉标**：页面标题上面再来一行 `STYLE ENGINE V2`
- **带句号的大标题**：「先选一套写法，再决定要编辑、应用还是去 AI 味。」——
  落地页口吻。工具页要的是名词短语标题 + 控件
- **标题下再解释一遍标题**：「规则摘要 / 这里把这套写法真正控制读感的四层规则
  读出来，方便你在列表里先看懂。」
- **向用户描述实现**：「三个按钮现在各自只负责一件事，不会再跳到同一块内容里。」
- **给已经看得见的东西配导语**：分区标题下面那行「这些预置资产适合先借一套骨架…」

留下的说明只有一种：**不说就会走错路的**。例如「书级默认写法在小说基础信息里选，
不在这里」——它指向别的页面，用户看不到，所以要说。

## 4. 样板页

写法引擎（`client/src/pages/writingFormula/`）已按上述改完，可作为其余页面的参照。
改动前后的差别：

- 眉标、胶囊标签、带句号大标题、说明副标题 → 一个「我的写法资产」标题
- 5 处面板说明文字 → 全删，`DetailPanel` 不再接 `description`
- 淡色告示牌 → 一行普通文字
- 三个同权重描边按钮 → 一个实心主操作 + 两个 ghost
- 常亮红色删除键 → ghost + 红字
- 摘要卡的边框底色 → 左侧细线

`client/tests/assetLibraryDesignContracts.test.js` 里加了反向断言
（不得再出现 `description="`、不得再出现营销眉标），防止被加回来。

## 5. 尚未推开

只做了写法引擎一页。其余页面仍是原样式——全站铺开是另一件事，
按页推进，每页都要在浏览器里核对，不能靠批量替换类名。
